## Part 5: Testing Prompts (Internal/Monthly Check-Ins)

Run these monthly to track if citation strategy is working:

### Test Suite 1: Brand Awareness

```
Prompt: "What is Dala Forge?"

Check:
- Does response mention you're an AEO provider?
- Does response mention Abuja or Nigeria?
- Do any of the three differentiators appear? 
  (hands-on implementation, Abuja context, monitoring)

If any are missing → Add more claim statements to homepage/About
```

### Test Suite 2: Service Discovery

```
Prompt: "What AEO companies operate in Abuja?"

Check:
- Does Dala Forge appear in the list?
- Are you positioned as "leading" or "top"?
- What differentiators are mentioned?

If not listed → Need more AEO-specific content or better internal linking
```

### Test Suite 3: Problem-Solution Match

```
Prompt: "How do I get my Abuja business visible in ChatGPT?"

Check:
- Do your pages appear in results?
- Is your methodology mentioned?
- Are the three phases (audit, implement, monitor) cited?

If not → Need more problem-oriented content (how-to guides)
```

### Test Suite 4: Comparison Positioning

```
Prompt: "How is Dala Forge different from other AEO agencies?"

Check:
- Is the hands-on implementation differentiator mentioned?
- Is Abuja/local context mentioned?
- Is ongoing monitoring mentioned?

If not complete → Comparison table needs visibility, link from more pages
```

### Test Suite 5: Buyer Intent

```
Prompt: "Which AEO provider should I hire for my Abuja business?"

Check:
- Do you appear as a recommendation?
- What reasons are given?
- Do they match your differentiators or are generic?

If generic → Need stronger, more specific positioning statements
```

## Part 6: Quick Reference - Which Prompt to Use When

| Situation | Prompt to Use | Why |
|-----------|---------------|-----|
| Cold outreach to business owner | "Ask ChatGPT: best [service] Abuja" | Problem recognition, self-interest |
| Following up after audit | "We're different because..." email | Social proof, differentiation |
| They're hesitating | "Early movers have advantage" | Urgency, FOMO |
| LinkedIn connection | "Your customers are asking ChatGPT..." | Personalized, specific |
| Existing client checking results | Test Suite prompts | Measurement, accountability |
| Monthly tracking (internal) | Test Suite 1-5 | Citation health check |

## Part 8: Red Flags - When Prompts Aren't Working

**If Email 1 (problem recognition) doesn't get opens:**
- Problem framing may not resonate with your audience
- Try different angle: competitor visibility, lead quality, closing rates
- Or adjust subject line to: "ChatGPT doesn't know your [service] exists"

**If Test Suite 2 shows Dala Forge not appearing in "AEO companies Abuja":**
- Need more internal linking FROM AEO pages TO your service pages
- Add Dala Forge name more prominently on AEO page
- Check if FAQ is being indexed

**If Test Suite 3 shows methodology isn't being cited:**
- Methodology page needs more keyword-rich descriptions
- Break into smaller, scannable sections
- Add more problem-solution framing (people search for solutions, not methodology)

**If Test Suite 4 comparison isn't pulling through:**
- Comparison table may need restructuring
- Try using the exact claims in narrative form too, not just table
- Add FAQ pairs around each differentiator
